方案 A — 目标数据模型（ER 图）

逐表确认字段与外键。🟢=新增   🟠=字段变更   ⚪=历史表不动

🟢 groups（新增 · 核心实体）
id (PK)
name (unique)  ← 改名只动这里
description
status (enabled / disabled)  ← 停用=软删除
group_ratio (float)  ← 从 GroupRatio map 迁入
topup_ratio (float)
sort (int)
created_at / updated_at
deleted_at (gorm 软删除 · index)
A 类活跃引用（字符串 → ID）
🟠 users
… group(varchar) → group_id (int) → groups.id
🟠 token
… group(varchar,'') → group_id (int)
语义保留：group_id=0 表示跟随用户分组
🟠 abilities（派生表）
PK: group_id + model + channel_id
enabled / priority / weight / tag
(group varchar → group_id int)
渠道多分组（关联表替代逗号串）
🟢 channel_groups（新增 · 多对多）
channel_id → channels.id
group_id → groups.id
PK: (channel_id, group_id)
index: group_id  ← 按分组反查渠道
channels
… group (varchar) 移除
多分组改由 channel_groups 表达
⚪ 历史表（完全不动）
⚪ logs · tasks · subscription · perf_metric
group (varchar) 保留旧名快照
不参与 ID 化、不回填
由此推出的关键不变量
  • 改名：UPDATE groups.name 一行 → users / token / abilities / channel_groups 全部自动跟随（都引用 ID）—— 核心目标达成
  • 删除/停用：groups.status=disabled + deleted_at（软删除），引用保留不丢；停用分组不再参与路由
  • abilities 重建：从 channel_groups × channels.models 笛卡尔积派生（替换原来拆分 channel.group 逗号串的逻辑）
  • 默认分组：迁移时把字符串 'default' 映射到对应 groups.id；保留 default 作为系统保留分组（不可删）
